# NestReady

임신 확인일부터 출산과 신생아 초기 생활까지, 부부가 함께 준비할 일을 관리하는 프로젝트입니다.

## Areas

- `checklists/` — 시기별 준비 체크리스트
- `records/` — 병원, 검사, 보험, 구매 기록
- `docs/` — 결정 사항, 참고 자료, 계획 문서
- `site/` — GitHub Pages에 배포하는 공개용 상태 대시보드

## Milestones

1. 임신 초기: 산부인과 첫 진료, 임신 주수·예정일 확인
2. 임신 중기: 검사 일정, 육아용품·주거 준비 계획
3. 임신 후기: 출산 병원·입원·산후조리 준비
4. 출산 후: 신생아 행정, 수유·수면·건강 기록

## Working principles

- 의료 판단은 담당 의료진의 안내를 우선합니다.
- 검사·진료·구매 결정은 날짜와 근거를 함께 기록합니다.
- 민감한 의료정보와 개인정보는 Git에 올리지 않습니다.

## Public dashboard

`site/`만 GitHub Pages 배포 대상으로 지정되어 있습니다. 공개 대시보드에는 준비 항목의 상태만 표시하고, 진료 일정·검사 결과·예정일·병원·계약·연락처 등 개인 정보는 절대 넣지 않습니다.

원격 저장소를 연결한 뒤 GitHub 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정하면, `main` 브랜치의 `site/` 또는 배포 워크플로 변경 시 대시보드가 배포됩니다.
