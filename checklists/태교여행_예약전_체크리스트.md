# 태교여행 예약 전 체크리스트

대상: 오키나와 4박 5일 초안
상태: 2026-10-05 산부인과 진료 전에는 예약·결제하지 않음

## 진료 후 바로 확인

- [ ] 난황·태아·CRL·심박과 확정 주수, 다음 진료일을 진료기록에 반영
- [ ] 12월 중순~1월 초 비행·해외여행 가능 여부를 의료진에게 확인
- [ ] 출혈·복통·유산/조산 위험 등 개인별 제한과 여행 중 즉시 진료가 필요한 증상 확인
- [ ] 항공 탑승 또는 보험에 필요한 진단서/영문 소견서 필요 여부와 발급 시점 확인
- [ ] 1차 선별검사·NIPT·정밀초음파 일정과 여행 후보일 충돌 여부 확인

## 날짜와 이동 방식

- [ ] 1순위 후보일(2026-12-14~18), 2순위(12-21~25), 3순위(2027-01-04~08) 중 1개 선택
- [ ] 인천↔나하 직항 왕복의 출·도착 시각이 무리 없는지 확인
- [ ] 나하 1박 + 온나손 3박 동선 또는 단일 숙박 동선 선택
- [ ] 렌터카 사용 여부 결정: 운전자 컨디션, 국제운전면허, 주차비, 반납 시간 확인
- [ ] 렌터카 미사용 시 공항 이동·택시/리무진 비용과 숙소 접근성 확인

## 항공

- [ ] 실제 운항사 기준 임신 승객 규정·필요 서류를 예약 당일 재확인
- [ ] 왕복 총액, 위탁수하물, 좌석 지정, 변경·환불·노쇼 조건을 동일 기준으로 비교
- [ ] 코드셰어면 실제 운항사 규정 확인
- [ ] 통로 좌석 가능 여부 확인
- [ ] 항공권 구매 후 예약번호·영수증은 `records/private/`에만 보관

## 숙소

- [ ] 객실 형태, 조식, 주차, 세탁·편의시설, 취소·환불 조건을 같은 기준으로 비교
- [ ] 나하 1박과 온나손 3박 각각 후보 2곳 이상 확보
- [ ] 비환불 요금 대신 무료취소 또는 변경 가능한 요금 우선 검토
- [ ] 숙소에서 가까운 편의점·식당·의료기관 접근성을 지도에서 확인
- [ ] 숙소 확정 후 상세 예약정보는 `records/private/`에만 보관

## 보험과 안전

- [ ] 보험 약관에서 임신 합병증·응급치료·긴급이송·여행취소/중단 보장과 면책을 확인
- [ ] 정상 임신·정기 진료·분만 관련 제외 조항을 확인
- [ ] 24시간 긴급지원 연락처·일본 내 의료지원 방식을 저장
- [ ] 여권 유효기간과 해외체류 기간을 확인
- [ ] 여행 전 일본 현지 날씨·태풍/항공 운항 정보를 재확인

## 출발 1주 전

- [ ] 진료 경과가 계획과 달라지지 않았는지 의료진 안내 기준으로 최종 점검
- [ ] 항공사 규정과 필요한 서류를 다시 확인
- [ ] 여행자보험 증권·긴급전화·여권 사본을 오프라인에서도 확인 가능하게 보관
- [ ] 무리한 관광·장거리 운전·고온 욕탕/사우나·해양 액티비티를 일정에서 제외 또는 의료진 지침에 맞게 조정
- [ ] 비상 증상 발생 시 항공·숙소 취소/변경 절차를 확인
